# Pure Dense / Akasha 可重复对照

## 边界与依据

运行：`node --import tsx --test --test-name-pattern="pure dense comparison" test/memory.test.ts`。完整回归可使用 `node --import tsx --test --test-concurrency=1 test/*.test.ts`，另运行 `npm run typecheck` 和 `npm run build`。

案例位于 `test/fixtures/memory-evaluation.ts`，全部合成，无真实聊天或凭据。21 个原始轮次包含中文/混合专名、User 偏好与 Assistant 建议、长原话、寒暄 hub、10 个无关背景、旧身份排除及同话题新身份。`required` 是查询必须覆盖的原话，`background` 是预先认可的相关背景；其余实际展示节点计作错误/无依据背景，即使它在合成 embedding 中相似。明确记录局部共同经历、远场复诊和高频 hub 的合成已提交学习信号，不把人工生成图说成真实聊天训练结果。

两个模式都经过真实 pi SDK、独立临时 SQLite、同一可控 HTTP embedding / 对话服务和模拟发送入口。每个查询从相同的原话、时间、冻结初始化、合成学习、排除和 embedding 映射重新准备；只用同样的连续片段选择器、来源去重和预算器注入，不让上一个测试请求污染下一个案例。先补齐相同向量再计查询延时，同时记录冷准备耗时及 embedding 请求数。

Pure Dense 用同样的消息/轮次余弦相似度与 0.35 直接阈值排序，不用字面、图、角色、衰减或资源排序；其 `memoryMode: "dense"` 只是程序级对照选项，不启用初始化或提交新的 Akasha 强化。默认生产模式仍是 Akasha。两个模式最大候选数相同，Top-8 同时统计，实际注入允许超过八条但预算相同（900，长片段案例 350）。不用分数增加或无限注入证明收益。

固定合成向量故意把未知专名与部分噪音归为同一方向，明确检验字面补救；游戏与伤口方向正交，检验学习关联；长消息按真实分片 API 聚合；相关性标注在运行前写定。这不是远程模型质量 benchmark，不能推断真实 embedding 服务、任意用户或真实陪伴效果。

## 本地结果

2026-10-03 的验收运行；表中是实际展示原话的覆盖，错误列按每案例节点出现计数，不是事实判断错误率。

| 案例 | Dense 必需覆盖 | Akasha 必需覆盖 | Dense / Akasha 错误背景 |
| --- | --- | --- | --- |
| 中文/混合专名 | 0/1 | 1/1 | 11 / 1 |
| 明确事实 | 1/1 | 1/1 | 0 / 4 |
| 局部关联 | 1/2 | 2/2 | 0 / 0 |
| 远场关联 | 1/2 | 2/2 | 0 / 0 |
| hub/无关背景 | 1/1 | 1/1 | 0 / 0 |
| User/Assistant 角色 | 1/1 | 1/1 | 0 / 0 |
| 90 天闲置直接查回 | 1/1 | 1/1 | 0 / 0 |
| 350 token 连续片段 | 0/1 | 1/1 | 1 / 1 |
| 遗忘后新身份 | 1/1 | 1/1 | 0 / 0 |
| 无关问题负例 | 无必需来源 | 无必需来源 | 11 / 2 |

合计必需来源覆盖 Dense 7/11、Akasha 11/11；Top-8 覆盖也分别为 7/11、11/11。认可的附加背景展示 10 / 14 次，错误背景 23 / 8 次。**明确事实案例中 Akasha 多带了 4 个无依据背景**，无关问题仍有误召回，不能宣称关联免疫错误或所有注入都正确。

十个查询的自动引文 token 合计约 3,828 / 5,344；单次不超过 900，长片段不超过 350。实发 wire 输入（含 system 和工具）约 3,000–3,800 个估算 token，小于共同输入额度 15,480。每个模式每个查询 1 次远程 embedding 请求，连同相同冷准备共 5 次；20 次实验共 100 次本地受控服务请求。查询全链路大致 0.15–0.32 秒，冷准备约 0.65–1.23 秒，耗时随机器和并行负载变化，不是性能承诺。Graph 带来额外 CPU、派生库写入和更多上下文成本，应与覆盖及错误背景同时看待。

测试逐条验证引文为原始 Unicode 连续区间、实际请求与总预算、角色来源、旧身份不展示、明确日志查阅不调用模型或学习，以及完整模式新学习仅来自实际展示的原 Top-8；不只检查名次或分数。故障重建、维度变更、后台/迟到送达/排除共存、原始学习配置恢复和普通工具存储保护由同一应用测试文件中的独立案例覆盖。
