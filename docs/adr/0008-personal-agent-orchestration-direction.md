# Personal Agent 统一组织工作

2026-10-12 方向讨论。本文记录用户逐项确认的目标与仍待决定的边界；尚未形成完整规格或最终架构批准，不表示运行时已经迁移。当前实现仍见 [ADR-0007](0007-personal-host-native-sessions.md)。讨论源：[Grok Bot 架构文章](https://www.joyehuang.me/blog/20261011---alwaysonagents/post)、[Akasha 专项调研](../research/akasha-personal-memory-2026-10-12.md)。

## 已确认的方向

Nailong 的目标是持续共事的 personal agent，编码是其中一种能力。本体直接处理轻量工作和授权范围内的短操作；耗时、输出量大或需要独立上下文的工作委派给帮手。研究、整理与编码使用统一委派入口，保留不同帮手的能力和执行边界。herdr 是外部编码 Agent 的接入与管理桥梁，子任务结果回到本体，由本体继续处理完整用户目标。

本体工具保持少量通用能力。连接器工具按需发现和加载，不将全部工具说明常驻模型上下文；加载工具不等于授予执行权限。用户基本同意按明确范围授权、按成果与影响选择验收，而非所有工作使用同一套独立验收流水线。具体工具清单及可强制执行的授权机制尚未确定。

用户插话时主对话优先响应，独立后台工作继续；关联任务的补充要求交给对应工作，归属不明确时询问，明确叫停才取消。支持用户明确授权的长期职责和选择性汇报；尚无首个持续跟踪场景，不据此启动实际监控。

记忆采用有预算的自动背景召回并保留主动搜索，保留原话、时间、角色与出处，不生成稳定偏好档案。历史作为相关背景，当前问题、指令与事实判断优先；高召回分数不证明真实性、当前有效性或行动权限。上游图算法升级尚未决定。

## 与当前实现的差异

ADR-0007 把本地 Pi 与 herdr 定义为平级 Task executor；目标方向要求编码结果回到本体继续工作，需重审执行入口与结果归属。当前主会话的文件读取只限技能目录，通用文件操作与 Shell 在任务会话；当前任务会话直接暴露所有已连接 MCP 工具。当前记忆通过工具调用召回，尚未实现本次确认的自动背景注入。

保留任务身份、实际执行身份、重启对账、资源冲突、停止、授权和交付的可靠性职责；业务地位缩小不能视为外部进程生命周期管理已经解决。如何让委派与本体共享这些保证，需要后续规格和验证证据。

## 运行与交互边界（已确认）

第一阶段保留 Windows 本地部署，明确区分会话与工作状态、工具执行及外部 Agent 管理。本机休眠或关机期间不承诺持续执行；恢复后对账和续接。是否引入常开远端主机留待实际需求。

本体可以静默处理后台事件，按需要显式发送用户消息。直接交办及时确认，完成、受阻或需要决定时汇报；普通后台进度不逐条推送。运行时承担可靠发送及频率限制，具体交付恢复规则仍需规格化。

用户明确设定的工作约定独立保存，支持查看、修改与撤销，不包含推断的性格或偏好，也不自动扩大行动授权。此项是约定管理的目标，不表示新增稳定偏好档案；生效范围和冲突处理待规格确定。

## 待决定

- 工作约定的生效范围、冲突处理，以及消息发送的恢复规则。
- 常驻工具清单、按需加载流程、记忆预算与去重、各类工作的验收机制。
- 持久化执行技术、委派恢复与取消、授权的可执行边界、预算限制与首阶段验收场景。

在这些边界明确并获得用户对整体理解的确认后，再发布讨论结论 Issue 和实现规格。
