# Personal Host with native Pi Sessions

Date: 2026-10-12. [Spec #157](https://github.com/CxHsin/nailong-bot/issues/157), tasks #158–#164.

Telegram/CLI and explicit plans enter one persistent Host on Windows. Host owns Task/Attempt, concurrency, authorization, recovery, independent acceptance and plain Delivery. Pi owns native Sessions, tool turns and compaction. Local files/commands and sole coding delegation, a named herdr executor, produce actual evidence.

This replaces production responsibilities in ADR-0001/0002/0004/0005/0006. Historical codecs, exclusions, archives and diagnostics remain offline; no second online replay loop remains. ADR-0003's recent-turn policy is historical. No browser, general desktop control, preference profile, remote scheduling platform or new RPC tier is added.

Task identity survives Attempts. Independent resources can run concurrently; overlapping canonical paths queue. Actual termination releases resources; unknown effects retain occupancy. Cancelled Tasks never automatically revive. Acceptance reads actual files and finite configured checks under current requirements; a concurrent revision change invalidates the verdict. Verified artifacts are copied and hashed before delivery.

Akasha keeps original sources and graph algorithms with memory-only durable facts. Confirmed ordinary delivery triggers idempotent learning; retry repairs learning without resending. No old online bootstrap remains. Reset/exclusion retires Sessions; forgotten sources cannot return through Task context. Source-dependent obligations stop or pause conservatively without deleting audit facts.

Shell/MCP use exact-action approvals because arbitrary commands lack an enforceable semantic boundary. Pi cannot claim downstream stop after opaque dispatch. herdr Codex uses workspace-write/on-request; Claude requires a verified policy. Network actions still depend on enforceable executor permissions.

Plain Telegram replaces drafts, tool reports and wait timers. Unknown pages never resend automatically. Explicit redelivery reuses results. Migration and release checks: [operations](../personal-agent-operations.md). Real Telegram acceptance remains pending.
